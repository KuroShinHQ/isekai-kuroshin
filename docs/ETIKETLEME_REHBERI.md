# 🧠 PSİKOLOJİK PROFİL BAZLI ETİKETLEME REHBERİ

## 📊 YENİ PSİKOLOJİK BOYUTLAR

### 1. **PSYCHOLOGICAL_ARCHETYPE** (Jung Arketipleri)
Oyuncunun psikolojik kimlik profili
- **HERO** (Kahraman) - Cesur, fedakar, toplum için savaşan
- **SHADOW** (Gölge Benlik) - Bastırılmış yön, karanlık benlik
- **SAGE** (Bilge) - Akıllı, düşünen, öğreten
- **REBEL** (İsyankâr) - Kurallara karşı, özgürlükçü
- **INNOCENT** (Masum) - Saf, temiz, iyimser
- **EXPLORER** (Kaşif) - Meraklı, keşfedici, özgür ruhlu
- **RULER** (Hükümdar) - Lider, kontrol sahibi, düzenli
- **CAREGIVER** (Bakıcı) - Koruyucu, şefkatli, fedakar
- **JESTER** (Soytarı) - Şakacı, eğlenceli, mizahi
- **LOVER** (Aşık) - Romantik, tutkulu, bağlı
- **CREATOR** (Yaratıcı) - Yaratıcı, artistik, yenilikçi
- **DESTROYER** (Yıkıcı) - Nihilist, yıkıcı, kaos getiren

### 2. **MORAL_TONE** (Ahlaki Ton)
Videonun ahlaki/ruhani atmosferi
- **REDEMPTION** (Kefaret) - Pişmanlık, telafi, ikinci şans
- **JUSTICE** (Adalet) - Doğru/yanlış dengesi, hak
- **VENGEANCE** (İntikam) - Öç alma, karşılık verme
- **FORGIVENESS** (Af) - Bağışlama, affetme
- **JUDGMENT** (Yargı) - Hesaplaşma, yargılanma
- **ACCEPTANCE** (Kabul) - Kabullenme, barış bulma
- **DENIAL** (İnkar) - Reddediş, inkâr
- **TRANSFORMATION** (Dönüşüm) - Değişim, evrim

### 3. **NARRATIVE_MOOD** (Anlatı Havası)
Videonun atmosferik tonu
- **TRAGIC** (Trajik) - Acı dolu, hüzünlü son
- **EPIC** (Destansı) - Büyük, kahramanca, destani
- **MELANCHOLIC** (Melankolik) - Hüzünlü, düşünceli
- **TRIUMPHANT** (Zafer) - Muzaffer, başarılı
- **HORROR** (Korku) - Dehşetli, korkunç
- **MYSTICAL** (Mistik) - Gizemli, ruhani
- **ROMANTIC** (Romantik) - Romantik, aşk dolu
- **COMEDIC** (Komedi) - Komik, eğlenceli
- **NOIR** (Karanlık) - Sert, karanlık, kasvetli
- **PHILOSOPHICAL** (Felsefi) - Düşünsel, felsefi

### 4. **PERSONALITY_TRAIT** (Big Five Kişilik)
Dominant kişilik özelliği
- **OPENNESS** (Açıklık) - Yaratıcı, meraklı, açık fikirli
- **CONSCIENTIOUSNESS** (Sorumluluk) - Disiplinli, özenli
- **EXTRAVERSION** (Dışadönüklük) - Sosyal, enerjik
- **AGREEABLENESS** (Uyumluluk) - İşbirlikçi, nazik
- **NEUROTICISM** (Nevrotiklik) - Duygusal, hassas

## 📝 ETİKETLEME İPUÇLARI

### ✅ İYİ ETİKETLEME PRATİKLERİ:

1. **Karma-Arketip Uyumu**:
   - Yüksek karma → HERO, SAGE, CAREGIVER, INNOCENT
   - Düşük karma → SHADOW, DESTROYER, REBEL
   - Nötr karma → EXPLORER, JESTER, CREATOR

2. **Moral Tone - Narrative Mood Sinerji**:
   - REDEMPTION + EPIC = Kahramanca kefaret
   - JUDGMENT + HORROR = Korku dolu hesaplaşma
   - ACCEPTANCE + PHILOSOPHICAL = Felsefi kabul

3. **Emotion - Mood Tutarlılığı**:
   - CALM → MYSTICAL, PHILOSOPHICAL
   - FEAR → HORROR, NOIR
   - JOY → COMEDIC, TRIUMPHANT
   - SADNESS → TRAGIC, MELANCHOLIC

### ❌ KAÇINILMASI GEREKENLER:

1. **Çelişkili Kombinasyonlar**:
   - DIVINE + HORROR (kutsal ve korkunç olmaz)
   - COMEDIC + TRAGIC (komedi ve trajedi çelişir)
   - HERO + VENGEANCE (kahraman intikam peşinde olmaz)

2. **Karma-Arketip Uyumsuzluğu**:
   - Yüksek karma + DESTROYER (yıkıcı iyiliksever olmaz)
   - Düşük karma + INNOCENT (masum kötülük yapmaz)

3. **Aşırı Karmaşık İsimler**:
   - Tüm boyutları kullanma, sadece gerekli olanları seç
   - Max 6-7 etiket yeterli
